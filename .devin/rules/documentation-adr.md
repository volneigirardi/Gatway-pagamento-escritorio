# Documentation and ADR Rules

- Use `docs/specs/TEMPLATE.md` for any non-trivial feature.
- ADRs are immutable once accepted. Override only with a new ADR.
- Keep `AGENTS.md` concise; put detail in rules, skills, or docs.
- Update `docs/project-state.md` when phase, decisions, modules, integrations, risks, or debts change.
- Write technical identifiers in English; explain in Portuguese when addressing non-technical stakeholders.
- Do not turn documentation into a conversation diary.
