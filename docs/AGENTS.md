# Documentation Rules

- ADRs are immutable once accepted; new decisions require a new ADR.
- Specs must use `docs/specs/TEMPLATE.md` for complex features.
- Project state is updated only when phase, decisions, modules, integrations, risks, or debts change.
- Glossary definitions use English terms with Portuguese explanations when needed.
- Agentic docs describe how agents should operate, not a transcript of conversation.
